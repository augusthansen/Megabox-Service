# 🔍 Getting Connection String from API Settings

Since your project is active, let's find the connection string in API settings:

## Step-by-Step:

1. **Go to Settings** (⚙️ icon in left sidebar)
2. **Click "API"** (not Database)
3. **Look for these sections:**
   - **"Project API keys"** - This has your API keys
   - **"Config"** - This might have connection info
   - **"Database"** section within API settings
   - **"Connection string"** or **"Database URL"**

## What to Look For:

In the API settings page, you might see:
- A **"Database"** section with connection parameters
- **"Connection string"** or **"Database URL"**
- Individual fields like:
  - Host
  - Port
  - Database name
  - User
  - Password

## Alternative: Check Project Settings

1. Click on your **project name** (top of left sidebar)
2. Or go to **Settings** → **General**
3. Look for connection information
