# 🔍 Get Connection Pooling String

We're getting closer! The pooling connection reaches the server, but we need the exact format.

## What to Check:

In **Settings → Database → "Connection pooling configuration"**:

1. **Look for a connection string** - It might be shown in that section
2. **Click the "Docs" button** - It might show connection examples
3. **Look for a "Connect" or "View connection" button**
4. **Check if there's a dropdown or link** that shows connection details

## Alternative: Check Project Region

The connection string format depends on your project's region. Can you check:

1. Go to **Settings → General**
2. Look for **"Region"** or **"Location"**
3. Common regions: `us-east-1`, `us-west-1`, `eu-west-1`, etc.

Or the region might be shown in:
- Project overview/dashboard
- API settings page
