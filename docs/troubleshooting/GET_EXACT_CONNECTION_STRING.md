# 🔍 Get the Exact Connection String

I can see your Database settings! Now I need to find the **exact connection string** that Supabase provides.

## What to Look For:

### Option 1: Scroll Down the Database Settings Page

1. On the Database settings page you're viewing
2. **Scroll down** past the sections you can see
3. Look for a section titled:
   - **"Connection string"**
   - **"Connection parameters"**
   - **"Connection info"**
   - Or tabs like: **"URI"**, **"JDBC"**, **"Golang"**

### Option 2: Check Connection Pooling Section

In the **"Connection pooling configuration"** section you can see:

- Look for a **"Connection string"** or **"Connect"** button
- Or check if there's a way to view the pooling connection string

### Option 3: Check the "Reset database password" Area

Near the **"Database password"** section at the top:

- There might be connection info shown there
- Or a link to view connection details
